# CodeSprite v0.2 优化计划

> 每一批必须通过单元测试、TypeScript 构建、Rust 测试和对应窗口的视觉回归后单独提交。未验证的功能不打勾。

## 第一批：基础质量与安全

- [x] 新建 `feat/v0.2-product-polish` 分支。
- [x] 修复功能球开关继承设置行最小宽度导致的横向溢出与复选框错位。
- [x] 补充 `tp-`、GitHub Token、JWT、AWS Key 和私钥的剪贴板敏感内容识别。
- [x] 启动时从本地缓存清除历史遗留的敏感剪贴板记录。
- [x] 已保存的旧更新占位地址自动迁移到 GitHub Releases。
- [x] 压缩设置结构，将低频配置折叠，常用操作改为图标按钮。
- [x] 在 `620×560` 与 `480×500` 两种窗口尺寸完成视觉回归，无横向溢出，开关命中与保存正常。

## 第二批：主题与桌面表现

- [x] 主题模型从纯颜色令牌升级为“令牌 + 装饰清单 + 动效参数”。
- [x] 冬日主题：霜边、雪粒、冷色水体和季节装饰。
- [x] 夏日主题：气泡、叶片、高光和明亮水体。
- [x] 功能球和工具窗继承主题装饰；在设置页、休眠水球与展开态完成视觉回归。
- [ ] 低性能模式与减少动画选项。

## 第三批：剪贴板快捷入口

- [ ] 用户可配置全局快捷键，默认行为参考 Windows 剪贴板入口。
- [ ] 快捷键弹出紧凑剪贴板窗，再次按下或外部失焦自动隐藏。
- [ ] 键位冲突检测、恢复默认和禁用快捷键。
- [ ] 搜索框自动聚焦，主要操作使用图标并提供 tooltip/无障碍名称。

## 第四批：待办与备忘重构

- [ ] 新增录入压缩为一条快速输入，更多字段按需展开。
- [ ] 常驻待办使用只读/快速完成视图，不复用完整管理页面。
- [ ] 增加“难度 × 紧急度”执行矩阵，可视化任务分布。
- [ ] 在列表中以位置、色阶和简短标签体现难度、紧急度与截止风险。
- [ ] 保持 Markdown 文档双向同步和托管区块兼容。

## 第五批：能力增强

- [ ] 端口工具升级为进程中心：默认展示开发相关监听端口和运行进程，可搜索、筛选、刷新。
- [ ] 端口释放、普通结束、强制结束分级处理并持续校验 PID。
- [ ] 工作区支持拖入桌面快捷方式、EXE、文件夹和网址。
- [ ] 工作区可编辑启动项、排序、延迟与启用状态。
- [ ] AI 搜词/命名加入真实请求基准，分别衡量首响应时间、总耗时和结果质量。
- [ ] 优化提示词、缓存、超时和本地快速结果，兼顾速度与工程可读性。
